## 任务说明

本任务使用影刀RPA采集佛山市国有建设用地使用权和矿业权网上交易系统中的历史交易数据。流程通过双层循环遍历前十页交易记录，跳过非“已成交”项目，采集并整理项目编号、成交时间、竞得人、交易土地面积、成交地价、地块位置等字段，最终写入Excel表格。
